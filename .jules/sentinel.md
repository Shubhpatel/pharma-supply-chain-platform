## 2026-10-23 - [Information Disclosure & Weak RNG] **Vulnerability:** Unhandled 500 errors were leaking raw backend stack traces or internal message details (`err.message`) to clients. Additionally, Draft IDs were generated using predictable `Math.random()`. **Learning:** A centralized error handling architecture was missing and insecure predictable random number generation was used for sensitive identifiers. **Prevention:** Always use a global error handling middleware in Express to mask internal error details and use `crypto.randomBytes` or `crypto.randomUUID` for sensitive identifier generation.
